# 设计系统

模板里的这套排版不是随手调的，每一项都有理由。改之前先读这一篇，
否则很容易把已经平衡好的东西改散。

## 字体：正文用宋体

```css
--serif: "Noto Serif SC", "Songti SC", "STSong", serif;   /* 标题、正文 */
--sans:  "Noto Sans SC", -apple-system, "PingFang SC", sans-serif;  /* 标签、按钮、元信息 */
--mono:  "IBM Plex Mono", ui-monospace, Menlo, monospace;  /* 时间、编号、英文栏目名 */
```

**正文用宋体是这套设计最关键的一个决定。** 中文刊物的正文本来就是宋体，
屏幕上这一改，整个页面从"网页"变成"印刷品"。满大街的 H5 都用黑体，
换成宋体立刻拉开距离。

黑体留给标签、按钮、元信息这些功能性文字，以及**需要跟宋体标题拉开层级的地方**——
比如政府项目名用黑体加粗，是公文语感，也说明它比活动名高一级。

## 字阶与间距

```css
/* 字阶：模数 1.25，基准 15px */
--t-xs: 11px;  --t-sm: 12.5px;  --t-base: 15px;
--t-md: 17px;  --t-lg: 21px;    --t-xl: 27px;

/* 间距：6 的倍数，别用中间值 */
--s1: 6px;  --s2: 12px;  --s3: 18px;  --s4: 24px;
--s5: 36px; --s6: 48px;  --s7: 72px;
```

所有间距都从这七个值里取。想要 15px 的时候用 12 或 18，
不要写 15 —— 一旦开了随手填数值的口子，页面的节奏感就散了。

**节奏规则：组内紧，组间松。** 标题和它的副题之间 6px，
两个内容块之间 18–24px。这个对比比绝对数值更重要。

## 配色

```css
--paper:    #F7F3EA;   /* 纸 */
--paper-2:  #F1EADC;
--paper-3:  #E9E0CE;
--ink:      #241D16;   /* 墨 */
--ink-2:    #6B6156;   /* 正文 */
--ink-3:    #9C9184;   /* 弱化信息 */
--indigo:   #16374C;   /* 靛蓝：标题、按钮 */
--indigo-2: #3A6B8A;
--cinnabar: #96271F;   /* 朱砂：只给最该被看见的那一处 */
--rule:     #D6CAB4;   /* 线 */
```

三条用色纪律：

1. **朱砂只用在一处** —— "邀请函"三个字、章号方框、一条收口的短线。
   用多了就不是强调色了
2. **底部渐变要压深** —— 纸色一路渐变到 `#E3D8C3`，页面才有"落地感"。
   不然下半部轻飘飘的，头重脚轻
3. **不用纯白** —— 白色块是整张纸上唯一不属于这套设计的东西。
   二维码底、卡片底都用纸色

## 布局

### 每屏内容垂直居中

```css
.inner { margin: auto; }
```

顶部对齐会让内容少的屏底部空出一大片，视觉重心不稳。
`margin: auto` 在 flex 容器里让内容块上下居中；内容超过一屏时自动归零，不会裁切。

### 封面用三段式

封面有五层信息，强弱和位置是定死的：

| 层 | 内容 | 处理 |
|---|---|---|
| 署名 | 主办／承办／执行 ＋ 项目名 | 字最小，**贴顶**，页眉性质 |
| 仪式 | 邀请函 / INVITATION | 字最大、朱砂，视觉焦点 |
| 主体 | 活动名 ／ 副题 ／ 一句话主张 | 靛蓝，核心信息 |
| 信息 | 日期 ／ 时间 ／ 地点 | 上下细线夹住，独立成块 |
| 引导 | 上滑提示 | 最弱，**贴底** |

```css
#cover .inner { display: flex; flex-direction: column; flex: 1; }
.cover-head { flex: none; }                                   /* 贴顶 */
.cover-body { flex: 1; display: flex; justify-content: center; } /* 中间三层整体居中 */
.cover-foot { flex: none; }                                   /* 贴底 */
```

**曾经踩的坑**：只给 `.cover-foot` 设 `margin-top: auto`，
所有剩余空间会全部堆在"主张"和"日期"之间，把封面撕成上下两个团块、
中间一个大洞，视觉重心悬空。三段式之后留白按节奏分配。

### 中文名单的对齐

两字名和三字名混排时，两字名要撑成三字宽才能对齐成栏：

```css
.nm {
  display: inline-block;
  min-width: 3em;
  text-align: justify;
  text-align-last: justify;   /* 关键：让最后一行也两端对齐 */
}
```

「李明」会被撑成「李　明」，与「王小波」对齐成栏。这是中文人名表的标准排法。

**行的对齐用 `align-items: center` 而不是 `baseline`** ——
职务标签是两行（"总负责／总策划"）而人名只有一行时，
baseline 会把人名吊在第一行上。

## 中文排版细节

- 正文两端对齐：`text-align: justify; text-justify: inter-ideograph`
- 首行缩进两字：`text-indent: 2em`
- 避头尾：`line-break: strict`
- 数字对齐：`font-variant-numeric: tabular-nums`（日期、电话、时间列必加）
- 标点用全角，英文缩写（AI、AIGC）保持原样
- 大字距要配 `text-indent` 补偿：`letter-spacing: .2em; text-indent: .2em`，
  否则整行会左偏一个字距

## 装饰元素

**文武线**（一粗一细两条平行线）是中式书籍的版心装饰，
用在封面顶部和页脚，把版面框完整：

```css
.wenwu i:first-child { height: 2px; }
.wenwu i:last-child  { height: 1px; margin-top: 3px; }
.wenwu.rev i:first-child { height: 1px; }        /* 页脚用反向 */
.wenwu.rev i:last-child  { height: 2px; margin-top: 3px; }
```

**点阵底纹**比网格线精细，也更接近"数字"的语感：

```css
background-image: radial-gradient(rgba(22,55,76,.09) 1.1px, transparent 1.1px);
background-size: 26px 26px;
mask-image: linear-gradient(#000 0%, rgba(0,0,0,.5) 46%, transparent 82%);
```

用 mask 让它只在上半部显影，下半部干净 —— 满屏都是纹理会很吵。
